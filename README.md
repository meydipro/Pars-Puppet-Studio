# Pars-Puppet-Studio
Pars Puppet Studio (پاپت‌استودیو) is a browser-based 2D Mesh Puppet Animation &amp; Lip-Sync Studio that turns any static character illustration, avatar, portrait, or meme into an expressive, loop-seamless animated puppet and exports clean, transparent GIF89a stickers and animations — 100% client-side with zero server uploads.
